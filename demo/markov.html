Transition matrix & Markov-chain lifespan

Quantifying how intertidal areas persist, convert between classes, and how long they are expected to last.

Transition matrixMarkov chainPersistence

What it computes

Given a sequence of yearly classified maps — for example the states {permanent water, intertidal, land} — DeltaSAT counts how many pixels move from each class to each other class between consecutive years. Normalising those counts row-wise gives a transition matrix whose entry Pij is the one-year probability of moving from class i to class j.

Transition matrix Pij = nij / Σj nij,   with   Σj Pij = 1

Projection & lifespan

A class distribution evolves by repeated multiplication with P; the stationary distribution is its eigenvector:

Evolution πt+1 = πt P  ·  πt+n = πt P n  ·  stationary: π = πP

Under a first-order Markov assumption, the time a pixel remains in a state with self-transition probability pii is geometrically distributed, so the expected lifespan is:

Expected residence time E[T] = 1 / (1 − pii)  years

The diagonal entries therefore summarise intertidal stability, while the off-diagonals reveal the dominant conversion pathways: intertidal → land indicates accretion or reclamation; intertidal → water indicates erosion or submergence.

The model assumptions are strong. A first-order Markov chain assumes the next state depends only on the current one and that P is stationary (constant through time). Geomorphic systems frequently violate both — trends, episodic events (storms, avulsions) and memory effects break stationarity. Estimate P over sub-periods and compare before projecting forward.

Assumptions & limitations

  • Classification error inflates spurious transitions; class definitions must be consistent across all years.
  • E[T] is a model expectation, not a directly measured lifespan — report it as such.
  • Results depend on the chosen state set and the time step (annual here).
