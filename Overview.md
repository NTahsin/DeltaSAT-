The source code, i.e., the backend files that I used for the development of the toolkit, can be found in the https://github.com/NTahsin/DeltaSAT-/gbm-delta-toolkit folder.

The webbased GUI which runs via the commandline, is in the https://github.com/NTahsin/DeltaSAT-/demo folder.
To use it, follow the steps below:
1. download both folders to the desired directory on your pc.
2. Run the command line with admin rights, and change directory via running"cd [location of the directory chosen]\demo"
3. run "python run.py"
4. this should open the toolkit for you
